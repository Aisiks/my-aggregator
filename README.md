# PRISM by Synapse

Совет из шести ИИ. Один вопрос → шесть агентов (Claude, GPT, Gemini, Grok, DeepSeek, Mistral) отвечают со своих ролей → председатель выносит **Решение Совета**: вердикт, где эксперты согласны и спорят, план на 7 дней и главный риск.

Интерфейс на русском, казахском и английском. Работает на телефоне.

## Что уже работает

- **Лендинг** (`/`) — hero с вопросом, «как работает», агенты, тарифы в тенге, FAQ, SEO-теги, Open Graph картинка
- **Приложение** (`/app`) — заседание Совета:
  - ответы агентов появляются по одному, как только готовы (стриминг)
  - Решение Совета сверху, ответы агентов ниже, длинные сворачиваются
  - можно выключить ненужных агентов (чипы над полем ввода)
  - уточняющие вопросы помнят контекст заседания
  - история в боковой панели, удаление, экспорт заседания в Markdown, копирование решения
  - мобильная версия с выезжающим меню
- **Демо-режим** — без ключа API сайт работает на заготовленных ответах и честно показывает плашку. Можно показывать людям уже сегодня.
- **Живой режим** — с ключом OpenRouter говорят настоящие модели.
- Защита: ключ только на сервере, лимит 12 вопросов в минуту с IP, вопрос до 4000 символов, тариф решает сервер, Markdown от моделей экранируется (нет XSS).
- Автотесты: `npm test`.

## Запуск у себя (2 минуты)

Нужен Node.js 18+. Ничего устанавливать через npm не нужно.

```bash
node server.js
# открой http://localhost:3000
```

Чтобы включить настоящие модели:

1. Зарегистрируйся на https://openrouter.ai, пополни баланс на $5 (хватит примерно на 1000 заседаний Starter).
2. Создай ключ: https://openrouter.ai/keys
3. Скопируй `.env.example` в `.env` и вставь ключ в `OPENROUTER_API_KEY=`.
4. Перезапусти `node server.js` — в консоли будет `LIVE`.

## Деплой на Vercel

1. Vercel → проект `my-aggregator` → Settings → Git → подключи репозиторий `Aisiks/my-aggregator` (если не подключён).
2. Settings → Environment Variables → добавь `OPENROUTER_API_KEY` (и `SITE_URL`).
3. Смёрджи ветку `night-build-mvp` в `main` — Vercel задеплоит сам.
4. Settings → Domains → добавь `prismai.kz`, когда купишь домен.

## Как устроен код

```
index.html            лендинг
app.html              приложение Совета
assets/css/base.css   общие цвета, шрифты, кнопки (DRY — объявлено один раз)
assets/css/landing.css
assets/css/app.css
assets/js/i18n.js     переводы RU/KZ/EN + данные агентов для интерфейса
assets/js/markdown.js безопасный мини-рендер Markdown
assets/js/store.js    история в localStorage (потом заменим на Supabase — меняется только этот файл)
assets/js/app.js      логика приложения
assets/js/landing.js  логика лендинга
api/council.js        серверная функция: POST /api/council, стрим событий
api/health.js         GET /api/health — режим demo/live
lib/agents.js         агенты: роли, модели, промпты — менять ИИ только здесь
lib/council.js        как проходит заседание (параллельные запросы + решение)
lib/demo.js           заготовленные ответы для демо-режима
server.js             локальный сервер для разработки (на Vercel не нужен)
test/                 автотесты
```

Путь одного вопроса:

```
браузер (app.js)
   │  POST /api/council  { question, history, agents }
   ▼
api/council.js  — проверка, лимит, открывает поток событий
   ▼
lib/council.js  — 6 запросов к OpenRouter параллельно
   │  event: agent     (каждый ответ сразу, как готов)
   │  event: decision  (председатель читает все ответы)
   ▼
браузер рисует карточки агентов и Решение Совета
```

## Модели и экономика

Один ключ OpenRouter даёт доступ ко всем вендорам. Модели задаются в `lib/agents.js`.

| Агент | Роль | Starter | Pro |
|---|---|---|---|
| Alex | Маркетолог | claude-haiku-5.5 | claude-sonnet-5.5 |
| Sam | Аналитик | gpt-6-luna-pro | gpt-6.1-sol |
| Max | Стратег | gemini-3.8-flash | gemini-4-argon |
| Zara | Критик | grok-4.3 | grok-4.7 |
| Leo | Разработчик | deepseek-v4.1-flash | deepseek-v4-pro |
| Nina | Юрист | mistral-small | mistral-large-4 |
| Председатель | Решение | claude-haiku-5.5 | claude-sonnet-5.5 |

Себестоимость одного заседания по ценам OpenRouter (октябрь 2026, ~400 токенов на вход и ~350 на выход у агента):

- **Starter:** ≈ $0.005 ≈ 2–3 ₸. 30 заседаний ≈ 80 ₸ при цене 2 490 ₸ — маржа огромная, лимит Starter можно поднять.
- **Pro:** ≈ $0.03 ≈ 15 ₸. 200 заседаний ≈ 3 000 ₸ при цене 6 990 ₸ — маржа ~55% до комиссий оплаты.
