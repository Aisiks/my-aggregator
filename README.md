# PRISM v2 — проверка ответов ИИ

PRISM задаёт вопрос трём моделям разных компаний (Claude, GPT, Gemini) независимо, а модель-судья показывает:
уровень согласия (0–100), что согласовано, где спор, что проверить у человека. Режим «Проверить ответ ChatGPT»
разбирает вставленный текст по утверждениям и даёт оценку доверия к нему (`trust`).

Почему не «совет из 6 агентов» (v1): точность даёт независимость ответов и их сравнение, а не роли персонажей
(arXiv 2508.17536, 2305.14325). Perplexity Model Council и LLM Council Карпатого сделали «много моделей в одном окне» товаром.

## Запуск
```
cp .env.example .env      # OPENROUTER_API_KEY — без ключа работает демо-режим
node server.js            # http://localhost:3000
npm test                  # 7 тестов
```

## Структура
- `api/verify.js` — POST, SSE-поток событий: start → model ×N → verdict → done
- `lib/verify.js` — параллельные вызовы моделей + судья; `lib/prompts.js`, `lib/json.js`, `lib/models.js`
- `assets/js/demo-engine.js` — общий демо-движок (сервер и браузер)
- `index.html` — лендинг, `app.html` — приложение, `synapse/index.html` — сайт компании

Ответы помечаются «Сгенерировано ИИ» (закон РК об ИИ, с 18.01.2026).
